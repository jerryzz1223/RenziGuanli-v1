# 离职结算

入口：薪酬 → 本月薪资 → 离职结算。

本版使用所选公司、月份的已锁定考勤终稿。每人本月只有一条薪资结算记录，正常月薪与离职结算使用不同计算器，共用月工资表和确认流程。

## 操作

1. 在离职结算页选择锁定名单中的员工，点击“办理离职结算”。
2. 核对结算日期、处理说明、结算依据以及17项原表输入。系统读取抵扣前工时；旧版来源无法还原时保留空白，须填写确认值。无金额或工时明确填写0。
3. 点击“试算预览”，查看原表单元格、公式和逐项结果。修改输入后重新试算。
4. 点击“确认输入并参与本月结算”。此操作保存输入及审核记录，并使未确认的旧试算失效。
5. 进入“本月算薪”，生成薪资输入、试算并复核确认。离职人员自动使用独立计算器。
6. 返回离职结算页查看个人明细，可打印带财务确认和收款签名栏的结算单。打印不会改变付款状态。

## 计算规则

规则版本：`termination-xlsx-v1`。来源：用户提供的《离职人员薪资计算.xlsx》D5:AI5。

- 薪资小计＝底薪＋津贴。
- 缺勤工时＝当月标准工时－基本出勤工时。周末加班不抵扣缺勤。
- 缺勤扣款＝薪资小计÷当月标准工时×缺勤工时，保留中间精度。
- 平日加班费＝ROUND(底薪÷174×1.5×平日工时,2)。
- 周末加班费＝ROUND(底薪÷174×2×周末工时,2)。
- 节假日加班费＝底薪÷174×3×节假日工时，按原表保留中间精度。
- 夜班津贴＝大夜班次数×45＋小夜班次数×24。此表只采用两档夜班输入。
- 旷工扣款＝薪资小计÷174×3×已确认旷工工时。原样表该工时为0，不根据员工离职状态自动推导扣款。
- 应付工资＝ROUND(薪资小计－缺勤扣款＋加班费＋夜班津贴＋绿苹果－红苹果＋全勤/住房津贴－旷工扣款,2)。
- 未纳税总计＝ROUND(应付工资－社保个人－公积金个人,2)。
- 实发工资＝未纳税总计－所得税－住宿伙食水电费－意外险/全额社保扣款。

所得税默认复现原表AF5不超过40000的分段公式。原表超过40000时直接返回整笔未纳税工资，系统对此区间要求勾选“使用财务确认税额”并填写确认值。勾选后填写0与未勾选是不同的处理方式。

全勤/住房津贴、绿苹果、红苹果、社保、公积金及其他扣款均以该离职单的确认输入为准。样例里的零不是所有离职员工的统一待遇规则。共同报表中的“水电扣款”包含原表AG5及AH5，个人明细保留两项独立金额。

## 来源及历史

输入保存在月度薪资参与决定的 `termination_inputs_json`，记录来源、原始值、确认值、规则版本及结算日期。金额及逐项公式保存在同一薪资结算记录的来源快照中，人员范围调整日志保留修改前后值。

来源或规则变化后必须重新核对。已确认工资不能被重算覆盖；同一员工同一月份的其他锁定版本存在已确认工资时，生成及确认均拦截。当前不办理跨月合并结算或整月考勤锁定前的即时结算。

## 验证

样例独立复算：缺勤扣款2197.391304347826，平日加班137.59，周末加班336.32，应付936.52，实发868.87。

`test_termination_settlement.py` 验证原表结果、取整、月份分母、非零加扣款、税额边界及无效输入。
`test_termination_payroll_integration.py` 使用真实生成函数和隔离数据存储验证混合人员、输入表、来源变化、旧离职决定及重复工资拦截。
`manual_termination_runtime_check.py` 读取本地当前锁定来源并执行不保存的样例预览，不审批或生成真实工资。
