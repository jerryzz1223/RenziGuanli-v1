# 薪酬配置中心操作指南

## 适用目标

本指南用于把永新员工定薪、考勤终稿、当月奖扣和计薪规则串成可锁定、可复核、可追溯的月度薪酬链路。日常管理只使用七步向导；标准工资项、工资表模板、字段映射和 JSON 仅作为兼容或专业设置，不再作为日常流程的强制入口。

页面保留完整七步流程。每一步使用独立路由和工作区：点击哪一步，下方只显示该步的用途、状态和操作入口。

## 七步操作顺序

### 1. 人员基础

前置要求：公司、部门、岗位、员工花名册已经建立。

操作入口：`薪酬管理中心 -> 步骤 1 基础资料`。本页只读预览；需要修改时点击“前往人事 · 员工花名册”。

需要完成：

- 核对公司、工号、姓名、部门、岗位、员工状态、入职日期和转正日期。
- 如有错误或缺失，到人事花名册修改，薪酬页不保存第二份员工主档。
- 本步不维护工资金额；员工定薪在第 2 步处理。

完成标准：当月在职员工都能用唯一工号匹配到完整人事资料。系统校验通过后，由负责人点击“确认并锁定本步”。

### 2. 员工定薪

前置要求：第 1 步已锁定。

操作入口：`薪酬管理中心 -> 步骤 2 员工定薪`。

为每位员工维护底薪、固定职能津贴、证书/多能工津贴、生效日和审批状态。只有当月有效、已批准且非测试值的记录会进入试算。

系统会对比在职花名册和已批准定薪，列出缺少定薪、待审批或仍使用测试值的员工；全部处理后再手动锁定。

### 3. 核算规则

前置要求：第 2 步已锁定。

操作入口：点击步骤“核算规则”。日常页面先显示固定薪资、月度变量和计算结果摘要；公式、字段映射和全部项目收起在“专业设置”。

本步确认应发、应扣、公司承担和导出口径。工资表模板可用于兼容标准 HRMS，但不再是本项目月度统算的强制前置条件。

完成标准：可执行公式和结算字段映射均通过系统校验，再手动锁定。

### 4. 考勤计薪

前置要求：第 3 步已锁定。

操作入口：点击步骤“考勤计薪”。

本步不导入当月考勤事实，只确认“考勤如何转成金额”：全勤奖门槛、缺勤扣款分母、平日/周末/节假日加班倍率、大/小夜班津贴。修改参数后必须重新校验和锁定。

### 5. 月度封板

前置要求：前四步均已锁定，考勤中心已产生同公司、同月份的锁定终稿。

操作入口：`月度来源`、`福利扣款`、`数据闭环导入`。

必须选择同公司、同月份、已锁定的考勤版本。薪资只读取：

- 已锁定月度考勤终稿；
- 已确认且符合资格的福利扣款来源；
- 已确认绩效、苹果树及月度变量；
- 同公司、同月份、同考勤锁定版本的数据。

未锁定考勤、待确认来源、重复/无法匹配员工或跨公司记录必须阻断。校验通过后手动锁定，形成本月数据封板。

### 6. 试算复核

前置要求：第 5 步已锁定。

操作入口：`本月算薪`。

先生成薪资输入表，再试算薪资结算表。重点核对人数、薪资小计、缺勤、1.5/2/3 倍加班、夜班、奖金、扣款、应付、计税、实发和公司成本。

输入表人数、考勤终稿人数和结算表人数必须一致。复核通过后手动锁定，系统同时把本月结算标记为已确认。

### 7. 报表发放

前置要求：薪资结算人数与输入表一致，差异已经复核，结算状态为已确认。

操作入口：`报表与发放`。

已确认结算可以生成工资汇总、部门成本、工资单和导出文件。完成导出/发放复核后再锁定第 7 步。历史月份使用当时的规则参数与来源快照。

## 独立步骤跳转

七个步骤分别使用以下工作区：

- 人员基础：只读预览，编辑跳转人事花名册。
- 员工定薪：已批准底薪、固定津贴、生效日和异动。
- 核算规则：应发、应扣、公司承担和导出公式。
- 考勤计薪：全勤、缺勤、加班和夜班如何转成金额。
- 月度封板：考勤锁定版本与已确认奖金、补贴、扣款。
- 试算复核：输入表、结算表和差异复核。
- 报表发放：已确认结果的导出与发放。

点击步骤会切换路由，不再滚动到同一长页的不同位置。

## 公式与规则修改要求

1. “计算公式”直接参与下一次未确认试算；“规则说明”只解释用途和资料口径。
2. 公式只能引用页面提供的字段和函数，不能执行 Python、JavaScript、SQL、属性访问或外部调用。
3. 每次保存自动增加公司公式版本；生效区间、修改人和来源进入版本记录。
4. 可下载“计薪公式”Excel，集中修改后先预览校验，再确认导入；任何错误行都会阻止整批导入。
5. 公式按公司隔离。结算保存公式版本、表达式、依赖字段和每步结果快照。
6. 已确认月份不可覆盖；考勤更正应产生新的锁定版本并重新走完整流程。

## 公式示例

- 薪资小计：`[底薪] + [职能津贴] + [证书及多能工津贴]`
- 缺勤扣款：`ROUND([全薪时薪] * [调整后缺勤工时], 2)`
- 平日加班费：`ROUND([底薪时薪] * [平日加班时数] * 1.5, 2)`
- 实发工资：`[计税工资] - [所得税] - [年终奖所得税] - [水电费及扣款] + [继续服务奖] - [已发福利]`

来源或资格规则仍可在“高级设置”查看，Excel 技术字段映射也只在高级设置维护。

## 最低验收案例

- 普通全勤员工：底薪、津贴、全勤、正常实发正确。
- 事假或病假员工：缺勤工时、全勤阶梯和缺勤扣款正确。
- 平日/周末/节假日加班员工：三种倍率和加班基数正确。
- 大夜班/小夜班员工：次数和单价正确。
- 宿舍员工：住宿、水、电分别有来源，汇总扣款正确。
- 调薪员工：生效日前后不串用薪资档案。
- 离职员工：只读取同公司锁定考勤和同版本变量。
- 跨公司测试：任何跨公司来源、删除、读取和确认都被拒绝。
