# 薪酬配置中心操作指南

## 适用目标

本指南用于把永新薪资资料中的工资项、规则、Excel 字段和月度来源配置为可计算的薪酬链路。配置中心不是第二套工资计算器：标准工资项、工资表模板和员工分配复用 Frappe HRMS；永新规则、字段映射、考勤锁定版本和福利来源由定制模块补充。

页面保留完整七步流程。每一步使用独立路由和工作区：点击哪一步，下方只显示该步的用途、状态和操作入口。

## 七步操作顺序

### 1. 基础资料

前置要求：公司、部门、岗位、员工花名册已经建立。

操作入口：`薪酬管理中心 -> 步骤 1 基础资料`。本页只读预览；需要修改时点击“前往人事 · 员工花名册”。

需要完成：

- 核对公司、工号、姓名、部门、岗位、员工状态、入职日期和转正日期。
- 如有错误或缺失，到人事花名册修改，薪酬页不保存第二份员工主档。
- 定薪、薪资档位和模板分配统一在第 4 步处理。

完成标准：当月参与薪资的员工都能用唯一工号匹配到完整人事基础资料。

### 2. 薪酬项目

前置要求：已理解公司实际工资表字段及其来源。

操作入口：`薪酬管理中心 -> 步骤 2 薪酬项目`。

主界面不再展示编码、Excel 列号和 JSON。页面先列出三个必需来源：员工薪资档案、已锁定考勤终稿、已确认月度变量，再按计算顺序列出薪资小计、缺勤扣款、加班费、奖金、应付、实发和公司成本。

历史 Excel 中的合并字段在配置页拆开显示，例如：

- 证书津贴、多能工津贴分别设置，结算时汇总到“证书及多能工津贴”。
- 全勤奖、住房补贴、学历补贴分别设置，结算时汇总到补贴奖金合计。
- 迟到扣款、全勤奖扣款分别确认，结算时汇总到惩处字段。
- 宿舍住宿费、水费、电费分别确认，结算时汇总到水电费及扣款。

点击任一计算结果进入公式编辑器。字段按“薪资字段、考勤字段、月度变量、计算结果”分组，点击字段可插入 `[字段名称]`；可使用 `IF`、`ROUND`、`MIN`、`MAX`、`ABS` 和 `SUM`。保存前系统校验字段、语法、自引用和安全性。

### 3. 工资表模板

前置要求：工资项已建立，税务属性、应发/应扣方向已经确认。

操作入口：点击步骤“工资表模板”，再点击“打开工资表模板”进入标准 HRMS 档案。

建议先建立：生产正式、生产试用、间接正式、间接试用、管理人员、离职结算六类模板。模板只决定项目组合和标准公式，不保存某位员工的当月金额。

完成标准：每套模板的应发、应扣和公司承担项目完整，停用项目不会进入新工资表。

### 4. 员工分配

前置要求：工资表模板已经启用。

操作入口：点击步骤“员工分配”。本页可打开标准模板分配，也可下载、导入或新增已批准员工定薪。

按公司、员工和生效日期分配工资表模板。同一员工同一生效期间只能有一套有效分配。员工定薪保存基础金额，模板分配决定使用哪些工资项。

### 5. 月度来源

前置要求：基础资料、工资项、模板和员工分配已经完成。

操作入口：`月度来源`、`福利扣款`、`数据闭环导入`。

必须选择同公司、同月份、已锁定的考勤版本。薪资只读取：

- 已锁定月度考勤终稿；
- 已确认且符合资格的福利扣款来源；
- 已确认绩效、苹果树及月度变量；
- 同公司、同月份、同考勤锁定版本的数据。

未锁定考勤、待确认来源或跨公司记录必须阻断。

### 6. 试算复核

前置要求：当月来源没有待确认记录，进入考勤终稿的员工全部有有效定薪。

操作入口：`本月算薪`。

先生成薪资输入表，再试算薪资结算表。重点核对人数、薪资小计、缺勤、1.5/2/3 倍加班、夜班、奖金、扣款、应付、计税、实发和公司成本。

规则修改只影响下一次未确认试算。人工调整必须保存项目、原值、调整值、原因和复核人，禁止直接覆盖已确认结果。

### 7. 报表发放

前置要求：薪资结算人数与输入表一致，差异已经复核，结算状态为已确认。

操作入口：`报表与发放`。

已确认结算可以生成工资汇总、部门成本、工资单和导出文件。历史月份使用当时的规则参数与来源快照，不因当前规则变化而重算。

## 独立步骤跳转

七个步骤分别使用以下工作区：

- 基础资料：只读预览，编辑跳转人事花名册。
- 薪酬项目：工资项、来源和计算公式。
- 工资表模板：模板列表与标准 HRMS 维护入口。
- 员工分配：模板分配、已批准定薪和异动。
- 月度来源：考勤锁定版本与已确认变量。
- 试算复核：输入表、结算表和差异复核。
- 报表发放：已确认结果的导出与发放。

点击步骤会切换路由，不再滚动到同一长页的不同位置。

## 公式与规则修改要求

1. “计算公式”直接参与下一次未确认试算；“规则说明”只解释用途和资料口径。
2. 公式只能引用页面提供的字段和函数，不能执行 Python、JavaScript、SQL、属性访问或外部调用。
3. 每次保存自动增加公司公式版本；生效区间、修改人和来源进入版本记录。
4. 可下载“计薪公式”Excel，集中修改后先预览校验，再确认导入；任何错误行都会阻止整批导入。
5. 公式按公司隔离。结算保存公式版本、表达式、依赖字段和每步结果快照。
6. 已确认月份不可覆盖；考勤更正应产生新的锁定版本并重新走完整流程。

## 公式示例

- 薪资小计：`[底薪] + [职能津贴] + [证书及多能工津贴]`
- 缺勤扣款：`ROUND([全薪时薪] * [调整后缺勤工时], 2)`
- 平日加班费：`ROUND([底薪时薪] * [平日加班时数] * 1.5, 2)`
- 实发工资：`[计税工资] - [所得税] - [年终奖所得税] - [水电费及扣款] + [继续服务奖] - [已发福利]`

来源或资格规则仍可在“高级设置”查看，Excel 技术字段映射也只在高级设置维护。

## 最低验收案例

- 普通全勤员工：底薪、津贴、全勤、正常实发正确。
- 事假或病假员工：缺勤工时、全勤阶梯和缺勤扣款正确。
- 平日/周末/节假日加班员工：三种倍率和加班基数正确。
- 大夜班/小夜班员工：次数和单价正确。
- 宿舍员工：住宿、水、电分别有来源，汇总扣款正确。
- 调薪员工：生效日前后不串用薪资档案。
- 离职员工：只读取同公司锁定考勤和同版本变量。
- 跨公司测试：任何跨公司来源、删除、读取和确认都被拒绝。
