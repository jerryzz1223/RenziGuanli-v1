# 入职管理导入与规则配置验收

验收范围：仅 `TEST-HRMS`；永新与公司 `1` 未写入。

## 发现与处理

- 原沟通表的“模块”页包含“入职（钉钉办理）”，但没有可回填的入职流程明细工作表；花名册只能作为员工主档来源，不能倒推出候选人、Offer 与入职审批历史。
- 系统已有标准 `Employee Onboarding`，但它要求已接受候选人和已提交且接受的 Offer；这条前置链路保留，避免绕过招聘直接建档。
- 原列表默认只显示 `Pending`，已完成、处理中和草稿容易被隐藏；现已取消该默认筛选。

## 新增闭环

```text
已接受候选人 + 已接受 Offer
  -> 员工入职衔接模板导入
  -> 预校验 / 暂存
  -> 人事审核
  -> Employee Onboarding 草稿
  -> 提交生效并生成办理任务
  -> 必办任务完成
  -> 创建 Employee 主档
```

## 规则维护

`入职规则配置` 进入标准 `Employee Onboarding Template`：人事可按公司维护任务、负责角色、开始日、时限、任务说明，以及是否阻断员工建档。列表中的“初始化标准入职规则”只在不存在时创建，不覆盖人工维护的规则。

## 验收结果

`run_form_import_e2e_acceptance` 在 `TEST-HRMS` 成功完成 29 类模板；新增“员工入职衔接”完成下载、填写、预校验、导入、审核、正式入职单提交和办理任务生成，失败数为 `0`。
