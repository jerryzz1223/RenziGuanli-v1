# 仅有花名册的服务器重建组织关系

花名册识别部门、职位与人员，不包含完整的管理层、分管范围、组线汇报关系。
部门列表和组织架构图共享组织配置；花名册部门记录继续用于员工归属。

## 已有整理正确的组织架构

1. 在正确的系统中进入「部门列表 → 组织配置 → 导出配置」。
2. 在目标服务器确认已导入花名册，公司、工号、部门和职位正确。
3. 进入「部门列表 → 组织配置 → 导入配置」，上传上一步的组织配置 XLSX。
4. 点击「校验并预览」，核对上下级、部门关联和固定人员的工号。修正阻断错误后重新预览。
5. 勾选「导入后按花名册自动更新人员」，点击「确认导入」。
6. 检查部门列表及架构图，并以目标服务器花名册人数验收。导入前备份可从完成弹窗下载。

此路径适用于尚无组织节点的服务器，可直接导入，无须先初始化。
「导出架构图」生成的图形 Excel、PNG、截图不是配置导入文件。
普通自动岗位会按目标花名册重新匹配；负责人、代理人、固定组线成员严格按工号核对。
来源机器不存在于目标花名册的固定人员，需要核对配置后再导入，不能按姓名自动猜测。

## 没有现成配置，从零建立

1. 完成花名册导入后，进入「部门列表 → 组织配置 → 从花名册初始化」。
2. 系统生成部门和职位节点，部门先平铺并标为待设置上级。缺部门、职位或无法识别类型的项目需要人工补充。
3. 用「新增组织节点」建立管理层、分管等实际层级。
4. 打开现有课室，点击「编辑节点」，选择「上级组织节点」并保存。例如把连续课放到已建立的分管一下。
5. 生产组、直线级等课室内部层级选择「部门内分组」，关联所属课室，按真实名单安排成员。
6. 保存完成后导出配置作为备份；以后人员随花名册更新，手工设置的上下级保持。

已有组织节点的公司会阻止再次初始化；直接编辑或导入现有配置即可。
同名职位无法证明某人属于哪条生产线，内部组线需要明确配置。

## 批量调整与删除

导出目标服务器当前配置，保持「节点编号」不变，修改「上级节点编号」再预览、导入。
职级高低由职级定义管理，部门上下级由上级节点管理，两者不能互相推断。
重复导入同一配置按编号更新；删掉文件中的一行不会自动删除系统已有节点。
误建的组织节点与员工引用的 Department 基础记录是不同对象，不能用清空部门表来重建。
若目标已经自动生成一套节点，再导入另一套编号的配置出现重复部门，应先核对匹配关系，不能直接重复新增。
