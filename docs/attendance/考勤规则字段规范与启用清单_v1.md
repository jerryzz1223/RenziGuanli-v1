# 考勤规则字段规范与启用清单 v1

## 目标

公司考勤必须读取 `HRMS Attendance Shift Rule` 和 `HRMS Attendance Scheduling Policy` 的结构化字段。Python 内置规则只用于公司尚未导入完整规则时的兼容，不是正式配置来源。备注、特别说明和任意公式文本只作审核依据，不直接参与考勤或薪资计算。

## 主键、范围与版本

- 公司内以 `rule_code` 作为稳定规则标识，员工范围只使用公司工号 `custom_employee_code`。
- `match_tokens` 用 `|` 分隔，所有词都必须出现在钉钉班次名称中；不得用模糊匹配猜测班次。
- 每条结果保存 `shift_rule_version`。规则变化只把历史数据标记为待重新校验，不得静默覆盖已审核或锁定结果。
- `effective_from` 决定新规则开始适用的日期。生效日前的数据继续按其原规则版本审计。
- 来源文件、工作表、行号、SHA-256 和原始行 JSON 必须保留。

## 可执行字段

| 分类 | 字段 | 格式或选项 | 对考勤的影响 |
| --- | --- | --- | --- |
| 身份 | `company` | Company | 隔离不同公司的规则。 |
| 身份 | `rule_code` | 公司内唯一文本 | 稳定更新及审计键。 |
| 身份 | `rule_name` | 文本 | 页面显示，不单独参与匹配。 |
| 匹配 | `match_tokens` | `词1|词2` | 所有关键词同时命中才可采用。 |
| 匹配 | `effective_from` | 日期 | 规则生效下界。 |
| 基本班 | `basic_time` | 一个或多个 `HH:MM-HH:MM` | 计划起止、跨日和班外时长。 |
| 基本班 | `basic_hours` | 非负小时 | 标准工时。 |
| 加班 | `weekday_overtime_time` | `HH:MM-HH:MM` | 固定平日加班时段及结束点。 |
| 加班 | `weekday_overtime_hours` | 非负小时 | 固定平日加班小时。 |
| 加班 | `weekday_overtime_mode` | 不提交加班单／加班单／无 | 固定平日加班的证据来源。 |
| 加班 | `extended_overtime_mode` | 加班单／不提交加班单／无 | 超过固定加班结束点后的证据要求。 |
| 加班 | `weekend_overtime_mode` | 不提交加班单／加班单／无 | 周末打卡是否可自动形成休息日加班。 |
| 加班 | `holiday_overtime_mode` | 不提交加班单／加班单／无 | 节假日加班来源。 |
| 特殊工时 | `special_workday_time` | 单个 `HH:MM-HH:MM` | 单独累计，不与平日加班重复。 |
| 休息 | `meal_deduction_rule` | 完整时间段及扣除小时 | 只扣实际打卡跨度覆盖的部分；来源已扣时不得重复扣。 |
| 取卡 | `punch_in_range` | `HH:MM-HH:MM` | 限定可采用的上班卡。 |
| 取卡 | `punch_out_range` | `HH:MM-次日HH:MM` | 限定可采用的下班卡。 |
| 夜班 | `small_night_rule` | 最低净工时 + 下班区间/下界 | 生成小夜班次数。 |
| 夜班 | `large_night_rule` | 最低净工时 + 下班区间/下界 | 生成大夜班次数，优先于小夜且不重复。 |
| 治理 | `calendar_weekend_mode` | 休息日加班口径／按工作日考勤 | 决定普通周末是否产生标准工时、请假、迟到、早退和旷工。 |
| 治理 | `max_*_hours` | 正数小时 | 服务端拦截超过工作日、休息日、节假日或每日上限的排班。 |

`remarks`、`extended_shift_rule`、`suggested_positions` 和来源原文均不可替代上述可执行字段。

## 发布门槛

1. GitHub 版本固定，代码和测试记录可追溯。
2. 完整规则表预览无结构错误；所有“待业务确认”项关闭。
3. 15 条班次规则均有唯一编码、匹配词、基本时段、取卡范围和来源行。
4. 排班治理规则明确普通周末口径、工时上限、一日多班及未排班打卡方式。
5. 使用真实但不写入的数据分别验证工作日、周末、调班、请假、漏卡、早退、固定加班、审批加班、特殊工时、小夜和大夜。
6. 对目标月份执行只读影响预览，核对员工数、变化日期、加班小时、夜班次数和异常增减。
7. 只有预览差异得到人事确认后才应用；锁定月份不得自动重算。
