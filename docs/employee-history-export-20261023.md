# 单员工全履历导出（2026-10-23）

入口：员工花名册 → 员工档案 →「导出全履历」。服务端方法：`hrms.api.employee_history_export.download_employee_history`。

导出当前 Employee 档案关联的全部可见历史，不合并其他 Employee 档案。工作簿在内存生成，返回下载，不新增可被分享的 File。目录标注每个区块来源、行数及读取状态；没有记录、权限不足、模型未安装分别显示。任一意外来源故障会中止下载，避免伪装成空记录。保留草稿/取消/历史版本时在来源记录及批次字段中标记，不自行重算业务累计。

## 数据来源

| 工作表 | 来源与范围 |
| --- | --- |
| 基本信息 | Employee；沿用现有模板启用和 export_enabled 开关，再取当前用户可读字段 |
| 教育背景、内部任职履历、外部工作履历 | 当前 Employee 的对应子表；不沿用详情页前五条限制 |
| 教育训练 | Training Result + Training Event + Training Result Employee；按已授权课程公司和员工链接匹配，未建链接的培训明细仅按当前公司工号补充匹配；取消的结果单和课程不纳入 |
| 苹果树 | HRMS Apple Reward Record、HRMS Apple Tree History Summary；只纳入当前公司可见且可导出批次下明确关联当前 Employee 的来源记录，保留批次状态和月份，不累计多版本 |
| 苹果树历史明细 | 已授权历史汇总的 source_rows_json；沿用苹果树明细的列语义，逐行验证 Employee 链接，仅投影需要的列，原 JSON 不直接导出 |
| 请假记录、请假审批证据 | Leave Application、HRMS Attendance Leave Evidence，按当前 Employee 精确过滤 |
| 考勤日记录 | 标准 Attendance，按当前 Employee 精确过滤 |
| 导入考勤日记录 | HRMS Attendance Day Check，保留导入批次历史；有效结果以月度终稿为准 |
| 考勤月度终稿 | 仅调用已有 get_monthly_final_preview(kind=signed, employee_code=当前员工工号)；导出可用锁定版本，不可用月份保留原因；再次过滤员工工号，不改异常、签字或终稿生成规则 |
| 人事异动、转正晋升、离职办理 | Employee Transfer、Employee Promotion、Employee Separation，按当前 Employee 精确过滤 |
| 奖惩记录 | HRMS Employee Reward Punishment，按当前 Employee 精确过滤 |
| 奖惩提报单、员工谈话表、材料附件 | File 明确附属当前 Employee，并检查 File 读取权限；兼容旧材料类型及 hrms_material_ 前缀；保留历史原件索引和受站点权限控制的链接，不提取扫描件正文 |
| 支援次数 | 复用支援分类新增 get_employee_support_counts 接口；显示所有有记录月份及累计，并附该接口的统计规则；不把可支援资格条数当次数 |

苹果树原有个人详情读取内部有 get_all 调用，不能直接借用来保证本导出的行级权限。因此本模块读取授权来源及版本；未关联 Employee 的历史工号记录需先在源模块核实归档，不按姓名猜测归属。月度有效统计可参照同一工作簿的考勤终稿与苹果树中心。

## 权限与格式

- 导出前必须具备 personnel_export 能力和目标 Employee 的 read/export 权限。
- 通用来源先检查模型 read/export 权限，使用分页 get_list 应用用户/列表权限，再检查逐单 read/export；不使用 SQL/get_all 或 ignore_permissions 查询。
- 子表字段不能用普通标量字段清单判断其可见性：检查父表的子表字段权限层级，再使用 parenttype 取得子表可读字段。
- 苹果树另检查 attendance_view；考勤终稿继续使用原接口角色要求。附件只提供本人已授权原件的链接。
- 单一来源最多读取 100000 行；超限中止，禁止静默截断。Excel 文本超出 32767 字符中止，避免声称完整却丢失正文。
- XLSX 沿用现有 openpyxl 导出依赖及 employee_report 水印设置，包括屏幕及打印水印选择。冻结表头、筛选、自动换行、A4 横向打印。
- 用户文本以字符串写入，公式样式文本不会变成可执行公式。仅给站点内部已授权文件添加超链接。

## 本地验证与边界

新增 tests/test_employee_history_export.py（23 项隔离及真实水印处理测试）和 tests/verify_employee_history_export_runtime.js（下载、失败、重复点击、选中员工入口运行时）。后端覆盖权限前置、逐单/字段权限、超过单页的历史、超限拒绝、培训他人行排除、附件读取、苹果树批次与历史行权限、支援接口契约、既有考勤终稿接口、全部区块收集及实际 XLSX 回读。已复用员工详情路由/中文展示/薪资概览、支援统计、水印测试进行相邻回归。

这些隔离测试不证明真实 Frappe 站点、角色配置、数据完整性、数据库、钉钉或部署通过。服务器需包含本分类源码及支援分类源码/新模型；支援模型尚未迁移时，工作簿明确显示未安装，不能显示为零次。上线后需以有权限人事、受限账号、无数据员工和有历史数据员工各导出核对。表单原件目前是附件归档，工作簿不包含原件二进制或 OCR 正文。

本分类只新增独立 API、前端模块、测试与本文档；共享 employee_detail.js 仅增加按钮。所有源码修改按文件绝对路径 SHA256 对应的原子目录锁完成；不提交、推送、部署或改写其他分类业务规则。

## 验证与优化补充

- 基本信息改为只读 get_single 读取已有模板；不再调用可能保存配置的模板同步器。
- 培训结果查询增加当前公司可见课程过滤；没有可见课程时直接返回，避免扫描全部结果单。缺少公司或培训模型分别说明。
- 通用来源统一保留 docstatus，区分未提交、已提交和已取消；历史明细展开后也执行 100000 行上限。
- 苹果树批次权限检查仅在单次导出的局部缓存复用；缓存按 Employee 和公司区分，不跨请求或用户保存。无权限导出批次字段时明确说明该来源未纳入。
- 下载端校验响应 MIME 与 ZIP 开头，拒绝空文件和错误文本。增加 180 秒超时及重试恢复；错误提示仅转义显示服务端用户消息，不显示 traceback。并发导出完成前保持等待状态，下载受阻也会回收对象 URL。
- 新增完整 21 工作表合成样本，经过真实水印模块处理后回读；验证每张表屏幕/打印水印、公式文本保持字面量及站内附件链接。

现有本机 Docker Frappe 17 开发站点使用 /workspace 挂载当前源码。已在数据库强制只读事务中，以 Administrator 对一个现有档案在内存生成 21 个工作表并检查 ZIP 完整性；Guest 被拒绝。该样本多数关联区块为空，因此不能代表所有非空真实业务来源已验收。验证进程的文件日志临时重定向至 /dev/null，以绕过容器缺失的日志目录；未修改容器目录、站点配置或数据库。HTTP 验证新增 JS 资源返回 200 且含当前下载校验代码，未登录下载返回 403。支援记录新模型在该站点仍未安装，已正确显示缺失状态；未执行迁移。浏览器已登录下载、受限人事账号及有完整非空历史的档案仍需站点验收。
